# XXXTentacionify
Hide your private files in Pictures
## How does it work?
This program uses a technique called steganography to hide files inside images. It modifies the least signifigant bits (LSB) of the color channels of the pixels in the image to store the data of the file. While the colours would be slightly modified, the human eye can't see it due to it being only a 255th of the red and green shades.
**In the app, you just drag a file on to the executable and it will create a image called "done.png". It contains the file you dragged on to the executable. Then you can drag done.png back to the executable and then it will give back the original file as "output". You can give the old file name back and it will be the exact same file again.**
